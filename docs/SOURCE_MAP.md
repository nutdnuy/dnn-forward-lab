# Source and implementation map

Primary source: Ivan Letteri, Giuseppe Della Penna, Giovanni De Gasperis and Abeer Dyoub (2022), *DNN-ForwardTesting: A New Trading Strategy Validation using Statistical Timeseries Analysis and Deep Neural Networks*. [arXiv:2210.11532v1](https://arxiv.org/abs/2210.11532v1), [DOI](https://doi.org/10.48550/arXiv.2210.11532).

Page numbers below refer to the supplied 24-page PDF, with its title page as page 1. The paper is research evidence, not an instruction source. No code, pretrained weights, charts, or market dataset have been copied from the authors.

## Ambiguities and discrepancies

- The paper prints `0.2%` dropout. That differs by a factor of 100 from a rate of `0.2`.
- ADX exit prose and Figure 22 disagree on whether the threshold is below or above 25. We use Figure 22.
- The candidate section calls the set “ten” indicators but names twelve. We include the named twelve and three combinations with fully specified rules.
- The paper's displayed MSE/RMSE formulas omit the averaging factor, and displayed MAE resembles a relative error. We use conventional metric definitions and document the units.
- The paper does not fully establish seed policy, validation partitioning, hyperparameter search, recursive versus observation-updated rollout, adjustment conventions, all indicator periods, or execution timestamps. This package explicitly fixes those choices.
- The original experiment describes a historical interval and trading-day counts that are insufficient to reconstruct an exact trading calendar and data snapshot. This project uses the supplied CSV's ordered session rows instead of inferring holidays.
- A lack of Pearson correlation does not establish independence. No such claim is inherited here.

## Technical primary references

- [PyTorch reproducibility](https://docs.pytorch.org/docs/stable/notes/randomness.html): seeded execution has version/platform limits.
- [PyTorch Adam](https://docs.pytorch.org/docs/stable/generated/torch.optim.Adam.html): optimizer API.
- [scikit-learn TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html): why chronological evaluation matters. The project implements explicit fold boundaries rather than directly calling this class.
- [scikit-learn leakage guidance](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage): fit preprocessing on training observations.
